# Credit Scoring under Delayed Labels

Credit risk modelling on Lending Club data (36-month loans), with a weekly simulation of a live scoring pipeline.

## Status

Week 0: project setup.

## Data

Kaggle dataset `wordsforthewise/lending-club`, file `accepted_2007_to_2018Q4`. Data is not stored in this repository; see setup below.

Column definitions: `docs/LCDataDictionary.xlsx`, from [Figshare](https://figshare.com/articles/dataset/Lending_club_dataset_description/20016077) (CC BY 4.0).
